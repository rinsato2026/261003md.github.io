# コーパス検索アプリケーション「中納言」の使い方

## 1. 中納言とは

国立国語研究所（国語研）が開発した、日本語コーパスを検索するための Web アプリケーション。単純な文字列検索に加えて、コーパスに付与された**形態論情報**（品詞・語彙素・活用形など）を使った検索ができる。

- URL：https://chunagon.ninjal.ac.jp/
- 利用は**無料**。著作権保護の観点から**ユーザ登録**が必要（メールアドレスがユーザ名になる）
- 登録コードが届かない場合は、国語研コーパス担当の問い合わせフォームから連絡する
- 検索できるコーパスはログイン後の選択画面に表示される（例：『現代日本語書き言葉均衡コーパス』BCCWJ、『日本語歴史コーパス』CHJ、『日本語諸方言コーパス』COJADS など）。利用できる検索機能はコーパスごとに異なる

## 2. 利用開始までの流れ

1. 公式サイトの「ユーザ登録」から、メールアドレスなど必要事項を入力して登録する
2. 届いた登録コードで登録を完了する
3. メールアドレスとパスワードでログインする
4. コーパス選択画面で、使いたいコーパスを選ぶ

※ 登録画面の項目・文言は変わることがあるので、画面の案内に従うこと。

## 3. 基本的な検索の手順

画面の名称はコーパスやバージョンで多少異なる。以下は一般的な流れ。

1. **検索方法を選ぶ**
   - 短単位検索：言語学的に小さい単位（短単位）で検索する。一番よく使う
   - 長単位検索：複合語などを含む、より長い単位で検索する
   - 文字列検索：形態論情報を使わず、表記の文字列そのもので検索する
2. **「キー」を指定する**（検索の基準となる語）
   - 語彙素：辞書の見出し（代表表記）。活用形や表記ゆれをまとめて探せる
   - 語彙素読み：見出しの読み（カタカナ）
   - 書字形出現形：文章中に実際に現れた表記
   - 品詞、活用形などの条件も組み合わせられる
3. **必要なら「前方共起」「後方共起」を追加する**
   - キーの前後にどんな語が来るかを条件にできる（例：「全然」の直後に否定表現が来る例だけを探す）
4. **検索範囲を絞る**（必要な場合）
   - コーパスによっては、年代・ジャンル・作品などのメタ情報で対象を限定できる
5. **検索を実行し、結果（KWIC 形式の用例一覧）を確認する**
   - キーの前後の文脈とともに用例が表示される
6. **結果をダウンロードして集計する**
   - 「検索結果をダウンロード」でファイルを保存し、Excel などで開く
   - Excel のピボットテーブルを使うと、ジャンル別・年代別などの集計ができる

## 4. 検索のコツ

- 活用する語や表記ゆれのある語は、まず**語彙素**で探すと取りこぼしが少ない。表記ごとの違いを見たいときは**書字形出現形**を使う
- 複数の語をまとめて探したいときは、条件指定の方法（ワイルドカード・正規表現など。コーパスによって選択肢が異なる）を確認して使う
- 最初は条件を少なくして検索し、結果を見ながら条件を足して絞り込む
- 検索条件（キー・共起条件・範囲）は、**あとで再現できるようにメモしておく**

## 5. 練習課題の例

「わたし」と「あたし」の使われ方を比べる。

1. BCCWJ を選び、短単位検索を開く
2. 書字形出現形で「わたし」「あたし」をそれぞれ検索する
3. 件数・ジャンルの分布をダウンロードして Excel で比べる
4. 用例を読み、会話文か地の文か、話者はだれかを確認する

※ 語彙素ではこれらが同じ見出しにまとまる場合があるため、表記の違いを比べるには書字形出現形を使う。実際の動作は画面で確認すること。

## 6. 結果を読むときの注意

- **自動解析の誤り**：形態論情報の一部は自動で付与されており、誤りが含まれる可能性がある。重要な用例は必ず目で確認する
- **件数の比較**：コーパスごと・ジャンルごとに規模が違うので、単純な件数ではなく、**規模をそろえた比率**（100万語あたりの頻度など）で比べる
- **コーパスの偏り**：収録された資料の時代・ジャンルに偏りがある。結果が「日本語全体」を代表するとは限らない
- **引用と利用規約**：用例を論文・レポートに使うときは、コーパス名・バージョン・検索条件・検索日を明記する。利用規約も確認する
