# 「わたし」と「あたし」の使用実態

## 1. 概要

「わたし」と「あたし」はどちらも一人称代名詞で、「あたし」は「わたし」の音が変化した形とされる。現代では、**「わたし」が場面・性別を問わず広く使える標準的な形**、**「あたし」はくだけた話し言葉で、主に女性が使う形**として位置づけられることが多い。

## 2. 成り立ち

「わたくし」→「わたし」→「あたし」という流れで語形が短くなったと説明される。

| 語形 | 位置づけ |
|---|---|
| わたくし | 最も改まった形。もとは「私的」の意の語 |
| わたし | 標準的な形。書き言葉・話し言葉の両方で使われる |
| あたし | 「わたし」の語頭が変化した、くだけた話し言葉の形 |
| あたくし | 「わたくし」の変化形。やや古風・丁寧でくだけた響きの形 |

※ 語源・変化の時期には諸説あり、細部は文献で確認が必要。

## 3. 歴史的な流れ

- **江戸時代**：「わたし」は男女ともに使われた。「あたし」は江戸後期ごろから、主に町人の女性の話し言葉に見られるようになったとされる。
- **明治以降**：男性は「ぼく」「おれ」などに分化し、「わたし」は改まった場面の語として残った。女性の話し言葉では「わたし」「あたし」が併存した。
- 落語など江戸の話し言葉では、男性が「あたしゃ」「あたしは」と言う例もあり、「あたし＝女性のみ」ではなかった。

## 4. ニュアンスと使われ方

- **わたし**：中立的・標準的。公的な場面、書き言葉、ビジネス、自己紹介などで使える。
- **あたし**：親しい相手との会話、くだけた場面向き。柔らかさ・親しみ・甘えなどの印象を与えることがある一方、場面によっては幼い・砕けすぎ・古風などと受け取られることもある。
- **フィクションでの役割**：小説・漫画・ドラマ・歌詞などで、「あたし」は女性キャラクターの話し方（いわゆる**役割語**）を表す記号として使われやすい。登場人物の年齢・職業・性格を示すために使い分けられる。
- **表記**：「あたし」「アタシ」と書き分けて、語感（軽さ・気だるさ・キャラ性など）を出す例がある。

※ 印象の評価は話者・世代・地域で差が大きく、「こう受け取られる」と断定はできない。

## 5. 使用実態をとらえる際の注意

- 「あたし」を実際に使う人の割合を示す、**信頼できる全国的な数値**は、確認したうえで引用する必要がある（本資料では数値を挙げていない）。
- 日常の話し言葉（本人の使用）と、メディア・創作に現れる「あたし」（イメージ）は **区別して** 考える必要がある。
- 地域差については、「東京（関東）の女性に「あたし」が多い」「関西では若い女性の一人称に「うち」が見られる」といった指摘があるが、いずれも **傾向** であり、調査に基づく確認が必要。
- 一人称の選択は、**相手・場面・自己呈示（どんな自分を見せたいか）** によって一人の中でも切り替わる。
